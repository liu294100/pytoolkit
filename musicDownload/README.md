# 🎵 Music Downloader Pro

现代化音乐下载器 - 多音源并发搜索、高速下载、精美界面

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![PyQt5](https://img.shields.io/badge/PyQt5-5.15+-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

## ✨ 特性

- 🚀 **极速响应** - 多音源并发搜索，流式结果展示，搜到即显示
- 🎨 **现代界面** - 深色渐变主题，动画效果，精心设计的 UI
- 🔍 **多音源支持** - 网易云、QQ音乐、酷我、酷狗、咪咕等 17+ 音源
- 💾 **智能缓存** - 搜索结果缓存，10分钟内重复搜索秒出结果
- 🌐 **代理支持** - 内置代理设置，支持国外音源
- 📦 **批量下载** - 支持全选/勾选下载，后台多线程下载

## 🚀 快速开始

### 环境要求

- Python 3.10+
- Windows / macOS / Linux

### 安装

```bash
# 克隆项目
git clone https://github.com/yourusername/music-downloader-pro.git
cd music-downloader-pro

# 安装依赖
pip install -r requirements.txt

# 运行
python music_downloader.py
```

### 一键安装（推荐）

```bash
pip install PyQt5 musicdl requests
python music_downloader.py
```

## 📖 使用说明

### 基本搜索

1. 在搜索框输入歌曲名或歌手
2. 选择想要搜索的音源（默认已选国内主流音源）
3. 点击"搜索"按钮
4. 等待结果流式加载（边搜边显示）

### 下载音乐

1. 在结果列表中勾选想要下载的歌曲
2. 选择下载范围（全部/已勾选/未勾选）
3. 点击"下载"按钮
4. 歌曲将保存到"下载音乐"目录

### 快捷操作

| 操作 | 说明 |
|------|------|
| Enter | 在搜索框中按回车快速搜索 |
| 全选 | 选中所有音源/结果 |
| 国内源 | 快速选中国内主流音源 |
| 右键菜单 | 单曲下载/全选操作 |

## 🔧 配置说明

### 代理设置

如需访问国外音源（Spotify、Deezer 等），可开启代理：

1. 勾选"代理"复选框
2. 填写代理地址（默认 127.0.0.1:7890）
3. 确保代理服务正在运行

### 缓存管理

- 搜索结果自动缓存 10 分钟
- 点击"清缓存"可清除所有缓存
- 缓存目录：`./搜索缓存/`

### 下载目录

- 默认：`./下载音乐/`
- 可通过"选择"按钮自定义目录
