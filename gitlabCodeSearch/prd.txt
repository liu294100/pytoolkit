我建议增加的功能

如果作为团队工具，下面这些功能会非常实用：

功能	作用
⭐ 收藏搜索	保存常用关键字
🔍 搜索历史	一键重复查询
📑 最近打开文件	快速返回查看
👤 作者过滤	只看某位开发者修改的代码
📅 最后提交时间	显示命中代码最近更新时间
📊 项目统计	每个项目命中数量
📂 文件树	左侧按目录浏览
🌙 深色主题	更适合长时间使用
🚀 后台自动同步	定时 git fetch 保持缓存最新
🔥 全局快捷键	类似 VS Code 的 Ctrl+Shift+P 搜索体验
推荐架构

我建议采用 MVC 架构，方便后续维护：

gitlab_code_search/
│
├── main.py                # 程序入口
├── gui/
│   ├── main_window.py     # 主窗口
│   ├── search_panel.py    # 搜索条件
│   ├── result_table.py    # 结果表格
│   ├── preview_panel.py   # 代码预览
│   └── settings_dialog.py # 设置窗口
├── service/
│   ├── gitlab_service.py  # GitLab API
│   ├── git_service.py     # clone/fetch/branch
│   ├── search_service.py  # ripgrep 搜索
│   └── index_service.py   # 索引管理
├── model/
│   ├── project.py
│   ├── result.py
│   └── config.py
├── cache/                 # 本地仓库
├── data/                  # SQLite 配置和历史
└── resources/             # 图标、UI 资源

这套结构可以支撑几十到几百个 GitLab 项目，后续也能增加代码历史、作者分析、调用关系等高级功能，而不用推倒重来。
