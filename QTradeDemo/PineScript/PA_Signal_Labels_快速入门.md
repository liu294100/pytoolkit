## 1. 安装与加载

### 步骤

1. **打开 TradingView** → 进入任意图表页面
2. 点击顶部工具栏 **"指标"** 按钮（fx 图标）
3. 在搜索框输入 **"PA Signal Labels"**
4. 从搜索结果中选择 **"PA Signal Labels — v9.0"** 并点击添加
5. 指标会以叠加模式（overlay）显示在K线图上


### 首次加载推荐设置

- **时间周期**: 5分钟 / 15分钟 / 1小时 均适用
- **品种**: 任意，对流动性好的品种效果更佳
- 默认参数已经过优化，无需修改即可开始使用

## 2. 信号识别入门

PA Signal Labels 识别 **6 种基本信号类型**，每种用不同颜色和编码区分：

| 信号 | 编码 | 含义 | 默认颜色 | 强度 |
|------|:----:|------|---------|:----:|
| **BO** (Breakout) | ±1 | 普通突破 | 🔵蓝(多) / 🔴红(空) | ★ |
| **CX** (Climax) | ±2 | 高潮K线（单边极端突破） | 🔷青(多) / 🩷粉(空) | ⚡ |
| **OB** (Outside Bar) | ±3 | 外包线突破（同时突破前K线高低） | 🟢绿(多) / 🟠橙(空) | ★★ |
| **Doji** | 4 | 十字星（多空均衡，OB 特殊情况） | 🟣紫 | — |
| **BigBO** (Big Breakout) | ±5 | 大突破（振幅或Z-Score超标） | 🩵青(多) / 🟣紫(空) | ★★★ |
| **FT** (Follow Through) | ±1+FT | 跟随确认（前一根信号的延续确认） | 浅蓝(多) / 浅红(空) | ★★ |

### 怎么看？

- **正数** = 多头信号（看涨），标签在K线**下方**
- **负数** = 空头信号（看跌），标签在K线**上方**
- **信号越大**（绝对值），重要性越高：BigBO(5) > OB(3) > CX(2) > BO(1)

### 优先级覆盖

当同一根K线满足多种信号时，高优先级覆盖低优先级：

```
BO(±1) → 被CX(±2)覆盖 → 被OB(±3)覆盖 → 被BigBO(±5)覆盖
```

## 3. 标签阅读指南

标签有两种显示模式，由 **"精简标签模式"** 参数控制：

### 精简模式（默认，推荐）

标签只有 **2行核心信息**，详细数据在 **tooltip（鼠标悬浮）** 中：

```
多BO ★ ↑强            ← 第1行: 信号类型 + 星级 + 趋势
顺势做多 🔶            ← 第2行: 策略建议 + 🔶表示有形态匹配
```

### 完整模式

标签展示全部文本信息，适合学习阶段：

```
📈多BO ★
↑强顺势 | 顺势做多 🔶
```

### 标签关键符号解读

| 符号 | 含义 |
|------|------|
| ★★★ | 信号质量极高（≥80%）|
| ★★ | 信号质量良好（≥60%）|
| ★ | 信号质量一般（≥40%）|
| ☆ | 信号质量较低（<40%）|
| ↑↑极强 | 趋势评分极强（≥70）|
| ↑强 / ↓强 | 强趋势（≥50）|
| ↑弱 / ↓弱 | 弱趋势（≥30）|
| TR | 震荡区间 |
| ⚠逆 / ⚠强逆 | 信号方向与趋势方向相反 |
| ⚠衰 | 高潮衰减期，信号可靠性降低 |
| ⛔MC | 信号与微通道方向相反 |
| 🔶 | 当前K线同时触发了 TWM 形态 |

### Tooltip（鼠标悬浮详情）

鼠标悬浮在标签上可以看到完整的趋势评分分解：

```
── PA v6 详情 ──
趋势评分: 65
  Swing:40 EMA:25 压力:10
  微通道:0 缺口:0
信号质量: 72.5%
Swing后: 5K
```

## 4. TWM 十大形态速览

指标内置 **TWM（The Wyckoff Method）十大高胜算形态**，分为顺势(P1-P6)和逆势(P7-P10)：

### 顺势形态（跟随趋势交易）

| 形态 | 名称 | 一句话描述 | 交易风格 |
|:----:|------|---------|---------|
| **P1** | 单边反转首回调 | 趋势刚翻转，第一次回调后恢复 | 趋势跟踪 4-6K |
| **P2** | 大突破后首回调 | BigBO后跟随确认→回调→恢复 | 趋势跟踪 4-6K |
| **P3** | 动能强势交易 | BigBO + 大实体 + 顺趋势 = 即时入场 | 剥头皮 1-2K |
| **P4** | 反转与跟进回调 | CX信号触发反转→FT确认 | 短线波段 2-4K |
| **P5** | BSB大K-小K-大K | 三根K线模式：大-小-大，方向一致 | 短线波段 2-4K |
| **P6** | 高潮后第二段 | 早期高潮→回调→趋势恢复 | 短线波段 2-4K |

### 逆势形态（反转交易）

| 形态 | 名称 | 一句话描述 | 交易风格 |
|:----:|------|---------|---------|
| **P7** | 弱势反转逆势 | 强趋势中出现弱势K线→顺趋势恢复 | 灵活波段 1-4K |
| **P8** | 内包K线反向 | 趋势中内包线→反向突破 | 灵活波段 1-4K |
| **P9** | 外包K线失效 | 外包线反向突破失效→顺趋势交易 | 灵活波段 1-4K |
| **P10** | 好运逆势 | 趋势末期大幅冲刺→暂停信号 | 趋势跟踪 3-10K |

### 形态标签

当形态评分 ≥ 60 时，会在信号标签上方/下方显示独立的形态标签（第2层）：

```
🔵P1反转首回调 ★★★
▲多 85 HTF↑
```

含义：P1形态 / 三星评分 / 做多方向 / 85分 / 大周期趋势向上

## 5. 界面元素一览

指标在图表上显示以下视觉元素：

### 三层标签系统

| 层级 | 内容 | 位置 | 说明 |
|:----:|------|------|------|
| **第1层** | 信号标签 | K线上方/下方（紧贴） | BO/CX/OB/BigBO/FT 信号 |
| **第2层** | 形态标签 | 偏移 1×ATR | TWM P1-P10 形态（评分≥阈值才显示） |
| **第3层** | Trap标签 | 偏移 2.5×ATR | 诱多/诱空陷阱警告 |

### 图标标记

| 图标 | 含义 |
|------|------|
| 💎 **BO!** | 突破型高潮（趋势早期的大K线） |
| ✖ **CL!** | 竭尽型高潮（趋势后期，注意反转） |
| ✖ **EXH!** | 力量枯竭（累计≥3次高潮） |
| ▲ △ | 微通道开始（向上/向下） |
| ▲ ▼ 三角形 | TWM形态多头/空头图标 |
| ✖ **⚡P3竭尽** | P3形态被竭尽过滤阻止 |

### 其他视觉元素

| 元素 | 说明 |
|------|------|
| **EMA 双线** | 黄色快线(20) + 橙色慢线(50) |
| **K线着色** | 信号K线用对应颜色着色；无信号K线半透明 |
| **趋势渐变** | 绿色(多头) / 红色(空头) 透明度随趋势强度变化 |
| **背景色** | 浅蓝灰色背景 = 震荡区间(TR) |
| **形态汇总表** | 右上角表格显示最近5个形态 |

## 6. 常用参数调节

以下是最常需要调节的参数，双击指标设置即可修改：

### 信号控制（最常调节）

| 参数 | 默认值 | 建议 | 说明 |
|------|:------:|------|------|
| **BO需FT确认才显示** | 1(开) | 新手保持开启 | 普通BO需要跟随确认后才显示，减少噪音 |
| **合并连续同类信号** | 1(开) | 保持开启 | 连续相同BO只显示第一个 |
| **信号最低优先级** | 1(全部) | 2或3 | 1=全部, 2=CX及以上, 3=OB及以上, 5=仅BigBO |
| **显示大突破** | 1 | 1或2 | 1=振幅倍数模式, 2=Z-Score模式, 0=关闭 |
| **标签显示阈值** | 60 | 60-80 | 形态评分≥此值才显示详情标签，提高则更精选 |

### 趋势系统

| 参数 | 默认值 | 建议 | 说明 |
|------|:------:|------|------|
| **趋势评分模式** | 1(v5) | 保持1 | 1=六维综合评分, 0=传统EMA |
| **多头/空头阈值** | ±30 | ±20~±40 | 趋势方向判断门槛，降低则更灵敏 |
| **EMA快线/慢线** | 20/50 | 可调整 | 影响EMA趋势线和评分维度2 |

### 形态识别

| 参数 | 默认值 | 建议 | 说明 |
|------|:------:|------|------|
| **启用形态识别** | 1(开) | 保持开启 | 关闭可隐藏所有TWM形态 |
| **形态冷却间隔** | 5 | 3-8 | 形态触发后等待N根K线才能再次触发 |
| **精简形态标签** | 1(开) | 保持开启 | 1=2行精简, 0=完整3行 |

### 显示控制

| 参数 | 默认值 | 建议 | 说明 |
|------|:------:|------|------|
| **精简标签模式** | 1(开) | 保持开启 | 核心信息+tooltip详情 |
| **显示EMA趋势线** | 1(开) | 按需 | 不需要可关闭减少图表杂乱 |
| **显示高潮图标** | 1(开) | 保持开启 | BO!/CL!/EXH! 图标 |
| **无信号K线半透明** | 1(开) | 保持开启 | 让信号K线更突出 |

## 7. 趋势评分系统简介

指标使用 **6维综合评分** 来判断当前趋势状态，总分范围 **-100 ~ +100**：

| 维度 | 满分 | 评估什么 |
|------|:----:|---------|
| **Swing 结构** | ±40 | 价格是否在创新高新低（HH/HL/LH/LL） |
| **EMA 位置** | ±30 | 价格与快慢EMA的相对位置、斜率 |
| **买卖压力** | ±30 | 近期多头/空头趋势K线的数量比 |
| **微通道** | ±15 | 是否存在连续上升/下降的微通道 |
| **缺口** | ±10 | 近期是否出现价格缺口 |
| **竭尽衰减** | — | 高潮后对评分进行衰减 |

### 趋势方向与强度

| trendScore | 趋势方向 | 强度等级 |
|:----------:|:--------:|:--------:|
| ≥ 70 | 多头 ↑ | 3 = 极强 |
| ≥ 50 | 多头 ↑ | 2 = 强 |
| ≥ 30 | 多头 ↑ | 1 = 弱 |
| -29 ~ +29 | 中性 → | 0 |
| ≤ -30 | 空头 ↓ | 1 = 弱 |
| ≤ -50 | 空头 ↓ | 2 = 强 |
| ≤ -70 | 空头 ↓ | 3 = 极强 |

> **提示**: 趋势评分的详细分解可以在标签的 tooltip（鼠标悬浮）中查看。

## 8. Trap 陷阱检测简介

Trap 检测用于识别 **诱多/诱空陷阱** — 即连续同向信号后突然反转的情况。

### 触发条件

1. 连续出现 ≥2 个（可配置）同方向信号
2. 出现**反向**信号
3. 可选：要求大周期(HTF)趋势确认
4. 可选：要求放量确认（成交量 ≥ 1.5倍均量）

### Trap 标签示例

```
🚨诱多TRAP ★★★
HTF↑ V2.1x
⚡反手空
```

含义：前面的多头信号是陷阱 / 三星强度 / 大周期多头（逆向确认）/ 放量2.1倍 / 建议反手做空

### Trap 强度

| 强度 | 含义 | 加分条件 |
|:----:|------|---------|
| ★ | 一般 | 基础条件满足 |
| ★★ | 强 | + HTF确认 或 + 放量 |
| ★★★ | 极强 | + 高级信号(CX/OB) 或 + 连续≥4次 |

## 9. FAQ 常见问题

### Q: 信号太多/太少怎么办？

**减少信号**:
- 提高 "信号最低优先级" → 2(CX及以上) 或 3(OB及以上)
- 开启 "BO需FT确认才显示"
- 开启 "合并连续同类信号"

**增加信号**:
- 降低 "信号最低优先级" → 1(全部)
- 关闭 "BO需FT确认才显示"
- 打开 "标记跟随K线"

### Q: 形态标签不显示？

- 检查 "启用形态识别" 是否开启
- 检查 "显示形态标签" 是否开启
- 降低 "标签显示阈值"（默认60，降到50试试）
- 检查具体形态的开关（P1~P10各有独立开关）

### Q: K线看起来和原始K线不一样？

v9.0 已注释掉 `plotcandle`，仅使用 `barcolor` 着色。如果你使用的是 v8.6.5 独立版本，其 `plotcandle` 仍然活跃，会创建一个可拖动的独立K线层。**解决方案**: 注释掉 `plotcandle` 那一行。

### Q: 大周期(HTF)怎么配置？

在 "大周期趋势判断" 参数组中：
- **时间框架**: 默认60（1小时），5分钟图建议用60，15分钟图建议用240
- **均线类型**: EMA 或 SMA
- **均线周期**: 快线20 + 慢线50

### Q: 震荡区间背景色是什么？

当市场被判定为震荡区间(TR)时，背景会变为浅蓝灰色。此时趋势信号的可靠性降低，建议谨慎操作。

### Q: 评分系统的权重可以调吗？

可以！在 "形态评分权重" 参数组中：
- 形态匹配 0.25 + 趋势背景 0.20 + 信号棒质量 0.25 + 市场阶段 0.15 + HTF对齐 0.15 = 1.00
- 将 HTF对齐权重设为0可以禁用大周期维度
